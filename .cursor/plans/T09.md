## Facts you need

- `credit_entries_wager_return_uidx` is a partial unique index. In SQLite the conflict target must repeat the predicate: `ON CONFLICT (wager_id) WHERE kind = 'return' DO NOTHING`. Use raw SQL if Drizzle can't express it, and check `meta.changes` to know whether this run paid.
- The settlement lease reuses `acquireRefreshLease` / `completeRefreshLease` (T02) with `provider = "settlement"`, `operation = "settle"`, `scope = "all"`.
- The jobs Worker (`workers/jobs/src/index.ts`) already has `Jobs.settle()` returning `{ skipped: ... }`. Replace that with the real call. The cron `20 * * * *` already maps to settle.
- No `platform`: `import { env, waitUntil } from "cloudflare:workers"`. Relative imports inside `src/lib/server/**`.

## Pieces

1. **`src/lib/server/data/settlement.ts`:** port `gradeCredits` verbatim, and `settleWagers` with identical semantics:
   - Claim the lease, or report `locked`.
   - Select open wagers (no `return` row) inner-joined to `games` on the canonical id, filtered to **terminal** statuses **before** the batch limit.
   - Grade each with `gradeSelection` from the stored `games.summary` **only**.
   - `won` pays the frozen `potential_return`, `void` (cancelled or postponed) returns the stake, `lost` pays 0. Still insert the `return` row at 0, as legacy does.
   - One insert per wager with the conflict clause above. A wager already paid is skipped and counted, never re-paid.
   - One wager failing is caught, logged and tallied, and the rest continue.
   - The lease closes in `finally`, with the same summary counts as legacy.
   - After the run, `notifyGroupSettlements` goes through `waitUntil`, respecting the per-membership opt-out. Port `group-notifications.ts` fully if T08a ported only the wager-placed part.
2. **Jobs Worker:** `Jobs.settle()` calls `settleWagers` and returns the legacy summary. `/api/cron/settle` already forwards to it.
3. **`src/lib/server/data/system-metrics.ts`:** port `getSystemMetrics` (recent ingestion runs, settlement health, the oldest open wager's age) to D1.
