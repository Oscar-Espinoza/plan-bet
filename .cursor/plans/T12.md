## Facts you need

- **Port the spine verbatim:** prompt building, `neutralize`, fact aliases (`[f1]`…), `parseBuddyReply`, the validation and retraction rules, caps (700 B prose, 1,400 raw), marker handling (`[pick:` `[draft:` `[note:`), the prohibited-language pattern, and the model settings (`OPENAI_MODEL` default, `reasoning.effort: "low"`, `text.verbosity: "low"`, `tools: []`, `store: false`). Change only imports, the runtime glue and the quota mechanism.
- **Quota:** legacy counted under advisory locks 6 and 7. On D1 the claim is **one** conditional insert of the user turn: `INSERT INTO buddy_messages … SELECT … WHERE (session count today) < 30 AND (ip-hash count today) < 100`. It's claimed only when `meta.changes === 1`. **No OpenAI call without a successful claim.** `OPENAI_API_KEY` missing short-circuits **before** any claim and returns the deterministic reply. A failed or unavailable claim also returns the deterministic reply (`metering_unavailable`), so metering fails closed.
- **IP:** use `CF-Connecting-IP`, hashed with `RATE_LIMIT_HASH_SECRET` (required; if it's missing, metering is unavailable and the reply is deterministic). Never store a raw IP.
- **Time zone:** the client sends its `Intl` zone. Otherwise use `request.cf.timezone`, else UTC (this replaces `x-vercel-ip-timezone`).
- **Streaming:** the route returns SSE from the Worker (`ReadableStream`). Validation runs on `response.completed`. The terminal frame carries `{ ok: false }` on retraction, and a stream that ends without a valid terminal frame is treated as dropped, exactly as legacy. Only finalized `ok` turns go back as history.
- **Contexts:** game, `/you`, group (membership re-checked every turn), `recall` and `none`, from `resolveContext`. Use `listBoardContext` from T03's `fixture-context-repository.ts`.
- `DELETE /api/buddy` clears the session's notes.
- The dialog code loads only when opened (dynamic import). The launcher sits beside the tour bar and clears the mobile nav, and appears on the pages legacy shows it on.
