## Pieces

1. **Game page wagering panel** (`src/routes/games/[id]/+page.server.ts` and the panel component):
   - Port `loadWagering`: unconfigured gives nothing, signed out gives `{ signedIn: false }` (T06 already renders that), and signed in gives the open/closed/unavailable state, balance, groups, `byMarket` record, this game's wagers and group picks.
   - Read the slip state from the `games` row, not the cached snapshot, as legacy does.
   - Stream it so the public page renders first: return the promise un-awaited from `load` and show the T06 skeleton while it resolves. The anonymous render, the one the edge cache stores, must stay byte-identical to T06's for a signed-out visitor.
2. **`bet-slip.svelte`:** port `bet-slip.tsx` faithfully:
   - Market grid and the armed selection (lime only on the armed price).
   - Numeric text stake input tied to the form by id, so Enter submits and native validation works. Typing over the balance warns and disables Place, and never rewrites the value.
   - The sticky `.bet-bar` after the markets, with `position: sticky; bottom: var(--tour-h)`.
   - Group selector.
   - A client-generated `idempotencyKey` (uuid). Keep it across an ambiguous failure; rotate it only when selection, price, stake or group changes, or after a confirmed success.
   - Error copy for each `PlaceWagerResult` reason, and the focused confirmation after placing.
   - On success, update the account chip balance locally before `refreshAll()`, as legacy does.
   - Keep `.wager-panel` at `overflow: clip`.
3. **`/you`** (`src/routes/you/+page.server.ts` and `+page.svelte`): port `legacy/src/app/you/page.tsx`:
   - Overview (balance, record, hit rate), open wagers, settled history with the legacy querystring filters (sport, outcome, range, scope, page) and pagination, record by sport and market, and Preferences (language, Rules, System, sign out via T07's `POST /sign-out`, and reset bankroll).
   - Each section streams independently, as legacy does.
   - Signed out: the legacy sign-in prompt.
   - `bets-history.svelte`, `reset-bankroll.svelte` and `reset-bankroll-dialog.svelte` (native `<dialog>`, with focus moving in on open and back to the trigger on close).
   - `/bets` and `/account` already redirect here (T04).
4. **Carry-over from T06 review:** the anonymous sign-in card on the game page must render only when auth is configured (`isAuthConfigured()`); when unconfigured, render nothing, as legacy does.
5. Spanish copy: every new string from legacy must already be in `messages.es.json`. Add any that are missing.
