## Facts you need

- adapter-cloudflare 8 passes **no `platform`**. Use `import { env, waitUntil } from "cloudflare:workers"` for bindings and background work, and `event.request.cf` for Cloudflare request properties (time zone is `request.cf?.timezone`).
- The Cache API (`caches.default`) works in local `wrangler dev` and on a custom domain, but does nothing on `*.workers.dev`. Prove caching locally with `pnpm build && pnpm preview:cf`.
- Shared modules from T01 live in `src/lib/shared/` and `src/lib/server/`. Use them; don't copy them again.
- Svelte 5 runes and SvelteKit 3 only (Appendix B). `$app/state` for page and navigation state; `refreshAll()` replaces `router.refresh()`.
- Icons: `@lucide/svelte`, importing each icon by name.
- No zod in client code. Pass components only the fields they render.

## Pieces

1. **Styles and fonts.**
   - Copy `legacy/src/app/globals.css` → `src/app.css` and `legacy/src/app/games/[id]/matchup.css` → `src/lib/styles/matchup.css`, **unchanged** except for font wiring. Import both from the root `+layout.svelte`, so both load with the shell.
   - Copy the four woff2 files that `legacy/src/app/fonts.ts` uses into `static/fonts/`. Get them from `legacy/node_modules/...` (run `pnpm --dir legacy install` if missing).
   - Write `@font-face` rules and the `--font-archivo`, `--font-plex` and `--font-dm-mono` variables the CSS expects. Use `font-display: swap`, the same weight ranges and `font-stretch` as legacy, plus metric-matched fallback faces. Copy the fallback `size-adjust`, `ascent-override`, `descent-override` and `line-gap-override` values from the CSS a legacy build emits: run `MATCHDAY_DATA_MODE=demo pnpm --dir legacy build`, then grep `legacy/.next/static/css` for `size-adjust`.
   - Preload the three text faces (Archivo, Plex, DM Mono 400) from `src/app.html` or `<svelte:head>` with `crossorigin`.
2. **Assets.** Copy `legacy/public/*` → `static/` unchanged (crests, stadium images). Add `static/robots.txt` matching `legacy/src/app/robots.ts` (allow `/`; disallow `/api/` and `/system`).
3. **Locals and hooks** (`src/hooks.server.ts`, `src/app.d.ts`):
   - `locals.locale`: `en` or `es`, from the `locale` cookie, else `Accept-Language`, using `requestLocale` from T01.
   - `locals.zone`: the `tz` cookie when it is a valid IANA zone, else `request.cf?.timezone`, else `UTC`. Use `viewerZone` from T01 for validation.
   - `locals.requestTime`: the request's `Date.now()`.
   - `locals.user`: `null` for now (T07 fills it). Also define `locals.signedIn` as "a Better Auth session cookie is present" (`better-auth.session_token` or `__Secure-better-auth.session_token`), whether or not it is valid.
   - Redirect `/bets` and `/account` to `/you` with status 308, keeping the querystring.
4. **Edge cache** (`src/lib/server/edge-cache.ts`, used from `hooks.server.ts`). Implement spec §3.4 exactly:
   - Pure functions: `isCacheableRequest(request, url, signedIn)`, `cacheKey({ version, locale, zone, sport, url })` and `isStorableResponse(response)`.
   - Allowlist: `/`, `/games/<id>`, `/rules` and `/system`, plus their SvelteKit data requests. Check the SvelteKit 3 docs for the data-request URL shape (legacy SvelteKit used `/__data.json` suffixes) and handle what v3 uses.
   - `publishVersion`: read from KV `env.PUBLIC.get("publish:version")`, memoized per isolate for 10 s, default `"0"`.
   - `sport`: the resolved board filter (the `sport` query parameter, else the `sport` cookie, else `all`), via `parseSportPreference` from T01. It applies to `/` only and is `-` elsewhere.
   - On a hit, return the cached response with `x-mp-cache: HIT`. On a miss, render; if storable, put a copy with `Cache-Control: public, s-maxage=60` through `waitUntil` and return it with `x-mp-cache: MISS`. Otherwise return `x-mp-cache: BYPASS`.
   - Browser-facing headers: `public, max-age=0, must-revalidate` for anonymous HTML; `private, no-cache` when `signedIn`. Never `no-store` on HTML.
   - Add `x-mp-version` on HTML.
5. **Root layout** (`src/routes/+layout.server.ts`, `+layout.svelte`): port `legacy/src/app/layout.tsx` (metadata → `<svelte:head>` with the same title, description, Open Graph and Twitter tags, translated) and these components into `src/lib/components/`, keeping class names and DOM structure:
   - `app-shell`: header, scroller, the bottom nav with Games / You / Groups and its active rule, and the back arrow.
   - `language-provider`: translator in Svelte context. Load the Spanish dictionary only for `es`, as legacy does.
   - `local-date-time` and the request clock: server renders in `locals.zone`; after hydration switch to the browser zone. Write the `tz` cookie (1 year, `SameSite=Lax`) when the browser zone differs from the server's. Never blank, no hydration-warning suppression.
   - `tour-bar`: only on `/` and `/games/*`.
   - `refresh-visible-page`: `refreshAll()` every 60 s while visible and on focus after the interval; never while a form field has focus; not on 2g/3g connections; as legacy.
   - `band-height`, `demo-stamp`, `breadcrumb`, `breadcrumb-portal`, `fast-link`, `navigation-preview`, `hydrate-store`, `route-error`.
   - `ui/banner`, `ui/button` (Radix `Slot`/`asChild` becomes a snippet or an `href` prop), `ui/card`, `ui/skeleton`, `ui/status-tag`, `ui/submit-button`.
   - Account control: render nothing for now (T07). Buddy launcher: leave the slot empty (T12).
   - Port `legacy/src/lib/store.ts` to `src/lib/state/store.svelte.ts` with runes, using the T01 `storage.ts` guard and the same localStorage key and version.
6. **Error pages:** `src/routes/+error.svelte` covering legacy `error.tsx`, `not-found.tsx` and `route-error.tsx`, with the same copy and layout.
7. **Placeholder:** keep `/` as a simple placeholder inside the shell (T05 builds the board). Don't build the board, rules or game page.
