## Rules for this ticket

- This is a **port, not a rewrite**. Copy each legacy file and change only what the table below says. Keep function names, comments, constants and logic identical.
- Inside `src/lib/shared/**` and `src/lib/server/**`, use **relative imports** (`./contracts`, `../shared/markets`), not `@/`, `$lib` or `#lib`. The jobs Worker (T03) bundles these files outside SvelteKit.
- Remove `import "server-only"` lines: files under `src/lib/server/` are server-only by SvelteKit's own rule.
- String environment variables: keep `process.env.X` reads. With `nodejs_compat` and a compatibility date on or after 2025-04-01, Workers populate `process.env` from vars and secrets. Bindings (D1, KV) are not involved in this ticket.
- `src/lib/shared/**` must not import zod, `node:*`, or anything under `src/lib/server/`, except `import type` (type-only imports are erased at build).
- Use `import type` for every type-only import (add the typescript-eslint `consistent-type-imports` rule if T00 didn't).
- Don't create routes or components. Nothing imports these modules yet; typecheck and lint still cover them.
